# 🇰🇿 YABGU: Қазақ Тіліндегі Дербес Тілдік Модель (From-Scratch Kazakh LLM)

**YABGU** — қазақ тілінің бай лексикалық қорын, агглютинативті грамматикасын және сингармонистік табиғатын негізге ала отырып, **нөлден бастап жобаланған және оқытылған дербес үлкен тілдік модель (LLM)**.

Бұл жоба сыртқы дайын API (OpenAI, Anthropic) немесе шетелдік модельдерді (LLaMA, Mistral) жай ғана қазақшаға аударып баптау (fine-tuning) емес. Мұнда архитектура, токенизатор, деректер құбыры және салмақтар толығымен өзіміз жасалды.

---

## 📌 Архитектуралық Ерекшеліктері (YABGU-50M)

| Параметр | Мәні | Сипаттамасы |
| :--- | :--- | :--- |
| **Параметр саны** | **46,936,576 (~46.94M)** | Есептелген таза салмақтар саны |
| **Қабаттар саны (Layers)** | **12** | Decoder-only Transformer блогы |
| **Жасырын өлшем ($d_{model}$)** | **512** | Hidden dimension |
| **Attention Heads** | **8** | Әр head өлшемі: 64 ($512 / 8$) |
| **FFN Архитектурасы** | **SwiGLU (1408)** | LLaMA/Mistral стиліндегі белсендіру |
| **Позициялық кодтау** | **RoPE (Rotary Position Embeddings)** | Ұзын мәтіндерге тұрақты контекст |
| **Нормализация** | **RMSNorm ($\epsilon=10^{-5}$)** | Жылдам әрі тұрақты градиент |
| **Сөздік көлемі (Vocab)** | **16,384 токен** | Byte-level BPE, 100% қазақша қамту, 0% OOV |
| **Салмақтарды байлау (Weight Tying)** | **Қосылған** | Input Embedding пен LM Head ортақ салмақта |

## 📊 Pretraining Нәтижелері (Tesla T4 16GB GPU)

Модель Google Colab жүйесіндегі **NVIDIA Tesla T4 GPU** қуатымен 12,000+ қазақша Уикипедия мақалалары мен Алаш әдеби классикасының 8.37 миллион таза токенінде оқытылды.

- **Өңделген токендер**: **24,576,000 токен** (3.1 толық дәуір).
- **Оқыту жылдамдығы**: **~31,000 токен/секунд**.
- **Бастапқы Validation Loss**: `9.80` $\rightarrow$ **Финалдық Validation Loss**: **`4.21`**
- **Бастапқы Perplexity (PPL)**: `18,046` $\rightarrow$ **Финалдық Perplexity**: **`67.99`**

## 💬 Модельдің Қазақша Мәтін Құрау Үлгілері (Inference)

### 1-Мысал:
> **Промпт:** `Қазақ тілі — `  
> **YABGU Жауабы:** `Қазақ тілі — қазақ тілінде жеке тіл ретінде, яғни қазақ тіліне ұқсас атауы. Абай — қазақтың ұлттық тілі. Қазақ тілінде "Қазақ тілі"...`

### 2-Мысал:
> **Промпт:** `Абай Құнанбайұлының қара сөздері `  
> **YABGU Жауабы:** `Абай Құнанбайұлының қара сөздері Алланың ең көне түрі — Абайдан өткен. Қазақтың дәстүрлі дүниетанымдары. Қазақтың салт-дәстүрлері: Қазақстан Республикасының Мемлекеттік сыйлықтары, Қазақстан Республикасының Конституциясы, Қазақстан Республикасының Мемлекеттік тіл туралы ұсыныстар...`

## 🚀 Жобаны Іске Қосу және Қолдану

### 1. Тәуелділіктерді орнату:
```bash
pip install -r requirements.txt
```

### 2. Интерактивті сөйлесу режимі:
```bash
python scripts/interactive.py
```

### 3. Жеке сөйлемді жалғастыру:
```bash
python scripts/generate.py "Қазақстанның бай табиғаты "
```
